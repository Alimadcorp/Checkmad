# CheckMad

## General purpose check-in software

### Features:

- Client side storage until synced
- Integrates with madstore
- Static frontend
- Simple and Fast

### Self hosting:

1. Clone the repo
1. Open the server folder `cd server`
1. Run `npm i` to install dependencies
1. Run `node index.js` to run server
1. Open `index.html` and select local server in options

### Contributing:

1. Make a fork of the repo
1. Make changes to the fork
1. Make a PR, include a summary all major and important changes made
